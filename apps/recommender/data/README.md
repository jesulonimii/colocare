# Synthetic demonstration data

`training.csv` is generated by `python app/generate_synthetic_data.py`. Its profiles, labels, and outcomes are synthetic assumptions for demonstrating a local training and inference pipeline; they are not patient records, clinical evidence, or treatment guidance.

To use approved de-identified data later, retain the CSV headers, replace the rows, and run `python -m app.train` from `apps/recommender`. This writes `model.joblib`, which the service loads on its next start.
